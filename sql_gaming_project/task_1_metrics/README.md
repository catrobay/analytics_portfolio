# Задание 1. Маркетинговая акция (DAU, WAU, MAU, Sticky Factor)

## Задача
В марте 2023 года маркетинг провёл акцию (чем чаще игрок заходит, тем больше бонусов). Акция шла первые 3 недели марта. Нужно было проверить, видим ли мы позитивный эффект акции в метриках активности.

## 🛠 Инструменты
- SQL (PostgreSQL)
- Metabase (выгрузка данных)
- Excel (визуализация)

## 🔍 Что сделано
1. SQL-запросы для расчета DAU, WAU, MAU без ограничения по датам.
2. Результаты и объединила их в одну таблицу в Excel.
3. Рассчет Sticky Factor (SFW = DAU/WAU и SFM = DAU/MAU).
4. 2 графика: динамика активностей и динамика Sticky Factor.

## 📈 Вывод
В марте 2023 года (во время акции) наблюдается рост метрик DAU и WAU. 
Sticky Factor также показывает положительную динамику в период первых 3 недель марта, что говорит о повышении вовлеченности игроков. 
После окончания акции метрики возвращаются к базовым значениям. Эффект акции можно считать позитивным.
