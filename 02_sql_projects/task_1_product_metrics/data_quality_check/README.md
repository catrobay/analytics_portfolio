# Задание 3. Чистота данных (Data Quality)

## Задача
Проверить масштаб проблемы «битых» сессий (где не заполнено поле `end_session`). Посчитать общую долю таких записей и в разрезе устройств (ios / android).

## 🛠 Инструменты
- SQL (PostgreSQL)
- Metabase

## 🔍 Что сделано
1. Найдено количество строк с пустым `end_session` и их доля от общего числа.
2. Расчет доли проблемных записей отдельно для `ios` и `android`.
3. Опредено процентное соотношение проблемных записей между платформами.

## 📈 Вывод
Выявлен процент ошибок в данных. 
Рекомендовано передать информацию в команду разработки для исправления логирования.
