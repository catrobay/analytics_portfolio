# Game Analytics: Zombie Revolution

Анализ метрик мобильной игры с помощью SQL и визуализации данных.

## 📌 О проекте
Проект включает 3 задачи по анализу игровых данных: оценка эффекта маркетинговой акции, поиск самых вовлеченных игроков и оценка качества данных.

## 🛠 Инструменты
- SQL (PostgreSQL)
- Metabase (выполнение запросов)
- Excel (визуализация)

## 📂 Структура проекта
- [Задание 1: Маркетинговая акция (DAU/WAU/MAU)](dau_wau_mau_analysis/)
- [Задание 2: Самые вовлечённые игроки](top_engaged_players/)
- [Задание 3: Чистота данных](data_quality_check/)

## 🔍 Навыки
- Написание SQL-запросов (JOIN, GROUP BY, CASE WHEN, агрегированные функции).
- Расчет продуктовых метрик (DAU, WAU, MAU, Sticky Factor).
- Оценка Data Quality.
