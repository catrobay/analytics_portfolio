# Задание 2. Самые вовлечённые игроки

## Задача
Найти топ-25 игроков, зарегистрированных в 2022 году, которые провели в игре больше всего времени. Учесть только завершенные сессии (`end_session is not null`).

## 🛠 Инструменты
- SQL (PostgreSQL)
- Metabase

## 🔍 Что сделано
1. Таблицы `users` и `game_sessions` по `id_user`.
2. Фильтр завершенные сессии и игроков с датой регистрации в 2022 году.
3. Расчет суммарного времени игры для каждого пользователя.
4. Определение топ-25 игроков.

## 📈 Вывод
Определены самые вовлеченные игроки. Именно на эту группу стоит ориентироваться при запуске новой акции с бонусами за время в игре.
