# A/B-тестирование новой рекомендательной системы

## О проекте
В рамках проекта проводился анализ результатов A/B-теста в онлайн-кинотеатре. Тестировалась новая рекомендательная система, цель которой — повысить конверсию пользователей в просмотр тайтлов (действие `play`).

## Инструменты
- **Python** (`pandas`, `numpy`, `scipy`, `matplotlib`)
- **Jupyter Notebook**

## 🔍 Этапы работы

### 1. Подготовка данных и очистка
- Проверен датасет на наличие пропусков (нуллов). Все строки с пропусками удалены с помощью `dropna()`.
- Выявлены «аномальные» пользователи, которые в ходе эксперимента попадали в обе группы (тест и контроль). 
- Такие пользователи были исключены из выборки, чтобы не искажать результаты.
- Общая доля исключений составила **7.37%** (778 записей).

### 2. Анализ результатов A/B-теста
- Рассчитана конверсия в целевое действие (`play`). Для каждого пользователя определен флаг: совершил ли он хотя бы один просмотр (`max_flag`).
- **Конверсия в контрольной группе:** ~28.3%
- **Конверсия в тестовой группе:** ~31.5%
- Для проверки гипотезы о равенстве средних проведен **t-тест Стьюдента** (`scipy.stats.ttest_ind`).

### 3. Визуализация активности (DAU / WAU)
- Рассчитаны метрики Daily Active Users и Weekly Active Users.
- Построены графики динамики DAU и WAU для визуализации пользовательской активности в период теста.

## 📈 Ключевые выводы для бизнеса
Результаты t-теста показали **p-value = 0.0079** (что меньше критического уровня 0.05). Это означает, что **различия между группами статистически значимы**. 
Новая рекомендательная система **статистически значимо повышает конверсию** в просмотр контента (с 28.3% до 31.5%). Рекомендуется внедрить новую систему на всех пользователей.
