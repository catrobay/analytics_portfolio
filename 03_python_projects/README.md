## Проекты в этой папке

### 1. [Анализ качества данных (Data Quality) в онлайн-кинотеатре SkyCinema](event_data_quality_analysis/)
**Задача:** Изучить логи событий плеера, найти аномалии и ошибки в данных, а также подготовить техническую записку для команды разработки.

**Что сделано:**
- Найдены аномалии в последовательности событий (например, пользователи снимали видео с паузы, но ни разу не ставили его на паузу).
- Выявлены пользователи с изолированными ивентами (всего 1 или 2 события), что указывает на ошибки логирования.
- Определены браузеры и устройства, где эти баги встречаются чаще всего (`desktop_web`, `Chrome`).


**Результат:** Jupyter Notebook с полным исследованием (`event_analysis.ipynb`)

### 2. [Анализ A/B-теста новой рекомендательной системы](ab_testing_analysis/)
**Задача:** Оценить результаты A/B-теста в онлайн-кинотеатре. Проверить, повышает ли новая рекомендательная система конверсию в просмотр тайтлов (действие `play`).

**Что сделано:**
- Проведена очистка данных: удалены нуллы и исключены клиенты, которые в ходе эксперимента попадали в обе группы (7.37% выборки).
- Рассчитана конверсия в целевое действие для контрольной и тестовой групп (28.3% против 31.5%).
- Проверка гипотезы с помощью **t-критерия Стьюдента** (`scipy.stats`).
- Построены графики активности (DAU, WAU).

**Результат:** Статистически доказано (p-value = 0.0079), что новая рекомендательная система значимо повышает конверсию. Ноутбук с решением — `ab_test_analysis.ipynb`.
