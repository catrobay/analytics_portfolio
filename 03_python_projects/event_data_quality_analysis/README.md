# Анализ качества данных в онлайн-кинотеатре SkyCinema

## О проекте
В рамках этого проекта я выступала в роли аналитика данных онлайн-кинотеатра. 
Задачей было изучить логи событий (ивентов) плеера, найти аномалии и ошибки в данных, а также подготовить техническую записку для команды разработки.

## 🛠 Инструменты
- **Python** (библиотеки `pandas`, `numpy`)
- **Jupyter Notebook** (среда для анализа)

## 🔍 Что было сделано (Задачи и решения)

### 1. Поиск топ-10 активных пользователей
- С помощью `groupby()` и `sort_values()` выделены 10 пользователей, совершивших больше всего действий.
- Определено, что чаще всего эти пользователи используют браузер **Yandex**.
- Самое популярное действие среди них — **`click`** (62.75% от всех действий).

### 2. Проверка данных на состоятельность (Поиск аномалий)
- Проведен анализ пересечения событий `playback_pause`, `playback_unpause` и `playback_start`.
- Выявлены «невозможные» последовательности: пользователи, которые снимали видео с паузы, но не ставили его на паузу; и те, кто ставил на паузу, но не включал проигрыватель.
- Определены устройства и браузеры, где эти баги встречаются чаще всего (`desktop_web` и `Chrome`).

### 3. Анализ пользователей с 1 и 2 событиями
- Выявлены пользователи с изолированными ивентами (только 1 действие).
- Проанализированы цепочки из двух событий. Составлен список ошибочных последовательностей (например, постановка на паузу без предварительного запуска плеера).

## 📈 Ключевые результаты
Найденные ошибки указывают на проблемы в логировании на стороне клиента (особенно на веб-платформе). 
Подробный список багов, примеры ID пользователей и рекомендации по исправлению вынесены в отдельный файл — **[техническая записка для разработчиков](technical_report.md)**.
