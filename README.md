# Портфолио аналитика: анализ продаж

## О проекте
Здесь собраны мои учебные проекты по анализу данных в Excel и Google Sheets.
Цель портфолио — показать навыки работы с данными, построения сводных таблиц,
графиков и дашбордов.

## 🛠 Инструменты
- Excel (сводные таблицы, формулы, графики, умные таблицы)
- Google Sheets (функция QUERY, дашборды)
- Аналитические расчёты: средневзвешенные, процентные приросты, динамика

## 📂 Структура репозитория
- `task_1_analysis/` — анализ торговых точек (ТЗ-1)
- `task_2_impact/` — влияние акций и сбоев (ТЗ-2)
- `task_3_dashboards/` — графики и дашборды (ТЗ-3)
- `presentation/` — итоговая презентация по курсовой

## 🔍 Что сделано по каждому заданию

### ТЗ-1: Анализ торговых точек
- Проведён анализ транзакций сети магазинов.
- Рассчитаны средневзвешенные показатели и процентные приросты.
- Выявлены аномалии в длительности операций.
- **Файлы:** [папка task_1_analysis](task_1_analysis/)

### ТЗ-2: Влияние технических сбоев и акций
- Оценено влияние маркетинговой кампании на выручку, прибыль и средний чек.
- Построены коэффициенты динамики по периодам.
- Сделаны выводы для бизнеса.
- **Файлы:** [папка task_2_impact](task_2_impact/)

### ТЗ-3: Графики и дашборды
- Созданы интерактивные дашборды с использованием QUERY и сводных таблиц.
- Визуализированы ключевые метрики в разрезах времени и категорий.
- **Файлы:** [папка task_3_dashboards](task_3_dashboards/)

### Курсовая работа
- Подготовлен аналитический отчёт о влиянии маркетинговой активности
  на финансовые показатели компании.
- **Презентация:** [папка presentation](presentation/)

## 📈 Ключевые выводы
1. Акции увеличили средний чек, но требуют контроля нагрузки на кассы.
2. Выявлены магазины с аномально низкой скоростью обслуживания.
3. Маркетинговая кампания окупилась за счёт роста повторных покупок.
