# 👋 Портфолио аналитика данных: Дарья Которобай

Аналитик данных с образованием в области мировой экономики и юриспруденции. Работаю с Excel, SQL и Python, анализирую данные, исследую продуктовые метрики и проверяю статистические гипотезы. В проектах уделяю внимание не только расчётам, но и практическим выводам для бизнеса

## Мой стек
- **Excel / Google Sheets** (сводные таблицы, дашборды, `QUERY`)
- **SQL** (PostgreSQL, Metabase, сложные `JOIN`, `CTE`, оконные функции)
- **Python** (`pandas`, `numpy`, `scipy`, `matplotlib`, `seaborn`)
- **Статистика** (A/B-тесты, t-тест Стьюдента, критерий Манна-Уитни, расчет MDE)
